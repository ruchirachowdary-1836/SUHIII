# Happy Birthday, Suhiiii 🎀

A pink coquette birthday diary for Suhi — React + Tailwind + Framer Motion.

- `npm install` then `npm run dev`
- Personal text (captions, timeline, reasons, letter) lives in `src/data/content.js`
- Replace photos: put originals in a folder and run `npm run photos -- <folder>`
- Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`
